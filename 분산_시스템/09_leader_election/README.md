# Leader Election (리더 선출)

## 개념

분산 시스템에서 여러 노드 중 하나를 리더로 선출하는 메커니즘입니다.
리더는 특정 작업을 조율하고 일관성을 보장하는 역할을 합니다.

## 필요성

- **조정 작업**: 분산 작업의 중앙 조정자 필요
- **단일 실행**: 특정 작업은 한 번만 실행되어야 함
- **고가용성**: 리더 장애 시 자동으로 새 리더 선출

## 알고리즘

이 구현에서는 **Bully Algorithm**을 사용합니다:
1. 가장 높은 ID를 가진 노드가 리더
2. 리더 장애 감지 시 선거 시작
3. 더 높은 ID의 노드가 있으면 양보
4. 자신보다 높은 ID가 없으면 리더 선언

## 구현 내용

- Bully Algorithm 구현
- 하트비트 기반 장애 감지
- 자동 리더 선출
- 리더 장애 시 재선출

## 실행 방법

```bash
go run main.go
```

## 학습 포인트

- 리더 선출 알고리즘
- 분산 시스템의 조정 문제
- 장애 감지 및 복구
- 실제 도구: ZooKeeper, etcd
