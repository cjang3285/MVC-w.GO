# Rate Limiting (속도 제한)

## 개념

Rate Limiting은 특정 시간 동안 허용되는 요청 수를 제한하여
시스템을 과부하로부터 보호하는 메커니즘입니다.

## 필요성

- **과부하 방지**: 너무 많은 요청으로부터 시스템 보호
- **공정한 리소스 사용**: 모든 사용자가 공평하게 리소스 사용
- **DDoS 공격 방지**: 악의적인 대량 요청 차단
- **비용 절감**: API 호출 횟수에 따른 비용 관리

## 알고리즘

### 1. Token Bucket (토큰 버킷)
- 일정 속도로 토큰 생성
- 요청마다 토큰 소비
- 토큰이 없으면 요청 거부

### 2. Leaky Bucket (누수 버킷)
- 고정된 속도로 요청 처리
- 버킷이 가득 차면 요청 거부

### 3. Fixed Window (고정 윈도우)
- 고정된 시간 창에서 요청 수 제한

### 4. Sliding Window (슬라이딩 윈도우)
- 이동하는 시간 창에서 요청 수 제한

## 구현 내용

- Token Bucket 알고리즘
- Fixed Window 알고리즘
- 사용자별 독립적인 제한
- 동시성 안전
