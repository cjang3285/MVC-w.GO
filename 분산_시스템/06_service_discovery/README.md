# Service Discovery (서비스 디스커버리)

## 개념

마이크로서비스 아키텍처에서 서비스 인스턴스를 동적으로 찾고 관리하는 메커니즘입니다.
서비스가 시작되면 자동으로 등록되고, 종료되면 자동으로 제거됩니다.

## 주요 기능

1. **서비스 등록 (Registration)**: 서비스가 시작될 때 자신을 등록
2. **서비스 조회 (Discovery)**: 필요한 서비스의 위치 정보 조회
3. **Health Check**: 서비스의 건강 상태 주기적 확인
4. **자동 제거**: 장애 서비스 자동 제거

## 사용 사례

- 동적 서비스 확장/축소 (Auto Scaling)
- 로드 밸런싱을 위한 서비스 목록 관리
- 서비스 간 통신
- Failover 처리

## 구현 내용

- 서비스 레지스트리 (중앙 저장소)
- 서비스 등록/해제 API
- Health Check 메커니즘
- 서비스 조회 및 필터링

## 실행 방법

```bash
go run main.go
```
